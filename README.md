# Muhammad Ishfaq — Premium Portfolio

A responsive dark glassmorphism portfolio built with React, Vite, Framer Motion, and Lucide icons.

## Run locally on Windows 10

1. Install Node.js LTS from https://nodejs.org/ if it is not already installed.
2. Extract this folder.
3. Open the folder in Antigravity.
4. Open Antigravity's terminal in this project folder.
5. Run:

   ```bash
   npm install
   npm run dev
   ```

6. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Edit content and project cards in `src/main.jsx`.
- Edit colors, spacing, glass effects, and responsive styles in `src/style.css`.
- Replace `src/assets/hero-portrait.png` or `src/assets/original-photo.jpg` with your preferred image.
- Update email and social links in `src/main.jsx`.

## Notes

The project cards are clearly presented as project concepts/areas, not fabricated client work or claimed results. GitHub and LinkedIn currently point to generic profile homepages; replace them with your own profile URLs when ready.
